Glossar, Abkürzungen und Index

Diese Elemente brauchst du nur, wenn sie Leserinnen und Lesern tatsächlich Orientierung geben.

Glossar und Abkürzungsverzeichnis

Führe Fachbegriffe alphabetisch im Glossar. Schreibe eine Abkürzung beim ersten Auftreten aus und setze die Abkürzung in Klammern. Ein separates Abkürzungsverzeichnis lohnt sich, wenn mehrere Abkürzungen wiederkehren.

Index (optional)

Wenn ein Index sinnvoll ist, markierst du wichtige Begriffe über Referenzen → Eintrag markieren. Word kann daraus unter Referenzen → Index einfügen einen Index erzeugen. Das ist aufwendig – nutze ihn nur bei einem echten Bedarf.

Fehlerdiagnose

Fehlt eine Überschrift im Inhaltsverzeichnis? Prüfe zuerst ihre Formatvorlage. Fehlt eine Abbildung im Verzeichnis? Prüfe, ob sie eine echte Word-Beschriftung besitzt. Erst dann aktualisierst du das Feld nochmals.
