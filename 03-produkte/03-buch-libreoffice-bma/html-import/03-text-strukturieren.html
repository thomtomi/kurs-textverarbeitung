2. Text strukturieren

Formatvorlagen sind das Fundament einer langen Arbeit. Sie verbinden deine Überschriften mit dem Inhaltsverzeichnis und sorgen dafür, dass eine spätere Änderung überall gleich aussieht.

Lernziele

  • Du verwendest für Lauftext, Überschriften und Listen passende Formatvorlagen.
  • Du beschränkst die Gliederung auf höchstens drei Ebenen.
  • Du verstehst, warum direkte Formatierung nur die Ausnahme sein soll.

Grundregel

Was eine Funktion hat, erhält eine Formatvorlage. Eine Kapitelüberschrift ist nicht einfach «grosser, fetter Text», sondern Überschrift 1. Ein Unterkapitel ist Überschrift 2. Lauftext bleibt Standard beziehungsweise die entsprechende Vorlage aus der BMA-Vorlage.

Die Vorlage ist bereits mit Überschriften 1–3 und einem Inhaltsverzeichnis auf maximal drei Ebenen vorbereitet. Nutze genau diese Ebenen; erfinde keine vierte Überschriftenebene.

Guter Start

  1. Setze den Cursor in eine Überschrift.
  2. Öffne mit F11 die Seitenleiste Formatvorlagen und wähle die passende Überschrift.
  3. Nutze für Fliesstext die Standardvorlage der Vorlage.
  4. Ändere das Aussehen einer Vorlage nur zentral – nie Kapitel für Kapitel.
