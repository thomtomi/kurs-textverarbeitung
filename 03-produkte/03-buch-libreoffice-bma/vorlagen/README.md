# LibreOffice-Writer-Vorlagen

- `BMA_Vorlage_Schriftliche_Arbeit.ott`: Vorlage für die schriftliche BMA.
- `BMA_Vorlage_Schriftlicher_Kommentar.ott`: Vorlage für den schriftlichen Kommentar.

Die Dateien sind echte LibreOffice-Writer-Templates (`.ott`). Beim Öffnen
erstellt LibreOffice eine neue Arbeitsdatei; diese bitte unter einem eigenen
Namen als `.odt` speichern. Die verbindlichen Vorgaben der BMA-Wegleitung
bleiben massgebend.
