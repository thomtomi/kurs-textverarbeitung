1. LaTeX unter Windows installieren

Unter Windows brauchst du zwei Bausteine: eine TeX-Distribution, die deine Datei in eine PDF umwandelt, und einen Editor, in dem du schreibst.

Empfohlene Kombination für Einsteiger:innen

MiKTeX + TeXstudio ist eine gut zugängliche lokale Kombination. MiKTeX stellt LaTeX bereit; TeXstudio bietet Syntaxfarben, Assistenten, einen PDF-Betrachter und Hinweise zu Referenzen.

  1. Lade den Basic MiKTeX Installer von der offiziellen MiKTeX-Seite herunter und installiere ihn.
  2. Wähle, falls abgefragt, dass fehlende Pakete automatisch installiert werden dürfen. Bestätige nur Pakete, deren Zweck du nachvollziehen kannst.
  3. Lade TeXstudio herunter und führe den Windows-Installer aus.
  4. Starte TeXstudio. Unter Optionen → TeXstudio konfigurieren → Erzeugen soll als Standardkompilierer pdfLaTeX stehen.

Installiere Distribution und Editor nur von den offiziellen Seiten. TeXstudio kompiliert nicht selbst; ohne MiKTeX bleibt die PDF-Erzeugung deshalb unvollständig.

Erster Funktionstest

Lege eine Datei main.tex an, füge den Minimalcode aus dem nächsten Unterkapitel ein und drücke F5 oder den grünen Pfeil. Erscheint eine PDF mit deinem Text, ist die Installation bereit.
