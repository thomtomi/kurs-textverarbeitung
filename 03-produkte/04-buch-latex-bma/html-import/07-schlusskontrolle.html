6. Fehler finden und Schlusskontrolle

LaTeX-Fehler sind normal. Die wichtigste Regel lautet: Lies die erste Fehlermeldung und prüfe zuerst die letzte Änderung.

Häufige Fehler

Meldung oder SymptomErste Prüfung
Undefined control sequenceBefehl falsch geschrieben oder benötigtes Paket fehlt.
File ... not foundDateiname, Ordner und Gross-/Kleinschreibung prüfen.
Missing } insertedIn der letzten Änderung eine geschweifte Klammer suchen.
«??» in der PDFNochmals kompilieren; bei Quellen Biber ausführen.
Bild an ungewohnter StellePDF erst vollständig lesen; Gleitobjekt nicht sofort erzwingen.

Arbeitsweise bei Fehlern

  1. Speichere eine Kopie des funktionierenden Standes.
  2. Gehe zur ersten roten Meldung im Log.
  3. Prüfe die genannte Zeile und die Zeile davor.
  4. Ändere nur eine Sache und kompiliere erneut.
  5. Wenn du feststeckst, bringe main.tex, die erste Fehlermeldung und einen Minimalfall zur Lehrperson.
